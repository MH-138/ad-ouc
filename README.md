认知障碍早期诊断临床数据采集系统 · 项目陈述

## 一、项目是什么

本项目是一款面向**阿尔茨海默病（AD）患者、家属及医生**的临床数据采集应用，以"智能对话访谈"为核心交互范式，形态为微信小程序（或 uni-app 打包的移动 App），运行于科室平板 / 手机端，服务于认知障碍早期筛查的基线评估。

**课程作业定位**：在 1 个月内交付一个**可演示的基础版本**，核心跑通"录入病人资料 + 填写量表 / 测试判断症状"主流程。

## 二、用户与角色

- **主试（研究者）**：发起评估、提问复杂量表、录入观察项。
- **患者（受访者）**：自评简单量表、回答提问、参与认知测试。
- **家属（知情者，可选）**：补充患者日常功能与行为变化。

## 三、核心设计理念

- **去表格化**：把冰冷的"填表"变成有温度的"对话"。
- **适老化**：大按钮、大字体、高对比、防误触。
- **离线优先**：断网可填写，重进可续聊。
- **智能辅助**：自动计分、红黄绿灯预警。

### 3. 可运行基础版原型（代码）

目录：`ad-ouc-prototype/`
已实现功能：

- 聊天式建档：姓名 / 性别 / 出生年（自动算年龄）/ 教育年限 / 身高体重 / 婚姻 / 居住 / 电话，自动生成研究编号。
- 10 个核心量表对话式评估：SCD-Q9、HAMD、HAMA、MMSE、MoCA-B、AVLT、VFT、FAQ、NPI、CDR，逐题大按钮 / 数字录入 / 表情尺 / 倒计时。
- 自动计分 + 红黄绿灯：每完成一个量表，聊天中以 🟢正常 / 🟡临界 / 🔴异常 反馈并给判定结论。
- 角色切换：顶栏下拉切"主试 / 患者 / 家属"，患者侧只显示泛化鼓励，分数与灯色在主试视图与导出中出现。
- 离线续聊：每步写入 localStorage，刷新 / 退出重进原地恢复。
- 一键导出 Excel：生成 `.xls`（Excel 可直接打开），含基本信息 + 各量表总分与分级，支持匿名化。

**技术说明**：纯前端（HTML + CSS + 原生 JS），零依赖、零构建，双击 `index.html` 即可运行；对话剧本与引擎解耦——新增量表只需改 `scales.js` 配置，无需改引擎代码（对应需求文档"仅扩展配置即可新增量表"）。
