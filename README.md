认知障碍早期诊断临床数据采集系统 · 项目陈述

## 一、项目是什么

本项目是一款面向**阿尔茨海默病（AD）患者、家属及医生**的临床数据采集应用，以"智能对话访谈"为核心交互范式，服务于认知障碍早期筛查的基线评估。

**课程作业定位**：在 1 个月内交付一个**可演示的基础版本**，核心跑通"录入病人资料 + 填写量表 / 测试判断症状"主流程。当前交付形态为**纯前端演示原型**（零依赖，双击 `index.html` 即可运行）；后续如需上线可平移到 uni-app（微信小程序 / 移动 App），见 `API接口设计.md` 与进度报告 P2 路线。

## 二、用户与角色

首页按三个通道分流，对应三类角色：

- **医师科研工作站（主试）**：发起评估、提问复杂量表、查看计分、生成综合报告、管理患者。
- **受试者自评（患者）**：自评简单量表、参与认知测试、查看泛化鼓励提示。
- **家属知情者（可选）**：补充患者日常功能与行为变化（FAQ / NPI / CDR）。

## 三、核心设计理念

- **去表格化**：把冰冷的"填表"变成有温度的"对话"。
- **适老化**：大按钮、大字体、高对比、防误触。
- **离线优先**：断网可填写，重进可续聊（localStorage）。
- **智能辅助**：自动计分、红黄绿灯预警、各维度小计。

### 3. 可运行基础版原型（代码）

目录：`ad-ouc-prototype/`
已实现功能：

- **三通道首页**：受试者自评 / 家属知情者 / 医师科研工作站，卡片式入口。
- **聊天式建档**：姓名 / 性别 / 出生年（自动算年龄）/ 教育年限 / 身高体重 / 婚姻 / 居住 / 电话，自动生成研究编号；含格式与合理性校验、跳过逻辑。
- **10 个核心量表对话式评估**（逐题大按钮 / 数字录入 / 表情 / 倒计时 / 主试词表面板 / 再认九宫格）：
  - SCD-Q9（9 题 + 6 道情景选择题，15 分制）
  - HAMD-17、HAMA-14（主试模式，每题带标准评分锚点面板）
  - MMSE-30、MoCA-B（标准子测验，约 30 分）
  - AVLT-H（主试词表面板防泄题 + 3 次学习回忆 + 干扰列表 + 延迟倒计时 + 再认九宫格）
  - VFT（60 秒计时 + 15 秒分段计数趋势）
  - FAQ-10、NPI-12（频率 × 严重度）、CDR（6 域 + Global 规则）
- **自动计分 + 红黄绿灯 + 各维度小计**：每完成一个量表，给出正常 / 临界 / 异常分级、结论与各维度得分；CDR 同时给 SB 与 Global。
- **综合诊断报告**：医师通道浮层，聚合已做量表分数 + 灯色 + 维度 + 总体提示，标注"非诊断"。
- **患者列表 / 管理者页**：医师通道列出全部建档患者、灯色摘要、快捷操作（选择 / 报告 / 导出 / 删除）。
- **角色切换**：顶栏切"主试 / 患者 / 家属"，切换前草稿保护 + 离开二次确认，不串流程；患者侧只显示泛化鼓励，分数与灯色在主试视图与导出中出现。
- **离线续聊**：每步写入 localStorage，刷新 / 退出重进原地恢复。
- **表格导入与缺失补填**：本地读取 CSV/TSV/HTML 型 `.xls`，识别中英文表头，缺失项回到对话补填；支持"由患者本人补填"。
- **一键导出 Excel**：生成 `.xls`（Excel 可直接打开），含基本信息 + 各量表总分 / 维度 / 分级 / CDR-Global，支持匿名化。
- **适老化与交互打磨**：大字体大按钮、语音朗读、进度条、当前题放大、HTML 转义、动效降级。

**技术说明**：纯前端（HTML + CSS + 原生 JS），零依赖、零构建，双击 `index.html` 即可运行；对话剧本（量表 + 建档）与引擎解耦，新增量表只需改 `scales.js` 配置。

## 八、当前限制（课程作业可接受）

- 数据仅存浏览器 localStorage，无云端持久化。
- 阈值仍为固定分段，未接入年龄 × 教育常模。
- 无后端，API 接口设计文档已就绪但前端未接入。
- 导出为 HTML 型 `.xls`，不支持解析二进制 `.xlsx`。
- 无随访时间轴；教师模板中 ADAS-Cog / BNT / STT / MES / Ecog / PSQI 等量表尚未纳入。
- 量表题目与阈值为课程演示配置，不可作为真实诊断依据。
