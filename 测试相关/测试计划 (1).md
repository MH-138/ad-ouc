# 认知障碍早期诊断临床数据采集系统 · 测试计划（V3.0）

> 版本：`V3.0` ｜ 更新时间：`2026-09-11` ｜ 适用目录：`ad-ouc-system/`
> 本文档面向**项目测试人员**，依据 `README3.md`、`P3_三端业务流程定稿.md`、`接口与数据表定义文档.md`、`01_当前实现差距与后续修改顺序.md` 编写。
> V1.0 纯前端原型的测试文档已归档于 `ad-ouc-v1.2/ad-ouc/`，本文档为 V3.0 全栈重构后的全新测试计划。

## 一、测试目标

1. 验证三端（受试者 / 家属 / 医生）彻底解耦：无前端角色切换、各端独立通道、医生端初始 `activePatientId=null`。
2. 验证云端数据库（Turso LibSQL）4 张核心表 CRUD 正确：`patients`、`assessments`、`drafts`（联合主键隔离）、`ai_consultations`。
3. 验证 16 个 API 接口契约一致性：路径、方法、参数、响应格式、错误码。
4. 验证全套神经心理量表计分算法：MMSE、MoCA-B、AVLT-H、CDR、FAQ、NPI、HAMD-17、HAMA-14、SCD-Q9、VFT、PSQI 等。
5. 验证身份证智能联动：18 位校验、出生年反算、周岁年龄、性别判定。
6. 验证空白保护：未作答量表项显示 `--` 不记 0 分、空白受试者灯色矩阵不误报。
7. 验证 OCR 病历结构化解析：门诊病历 / 出院小结图像 → 结构化字段 → 人工确认回填。
8. 验证 AI 临床研判闭环：0%→100% 动画 → 三段式意见 → 待审核队列 → 医生电子签名 → 写入正式诊断。
9. 验证 Excel 导出：全量表汇总、匿名化、含 Global 列。
10. 验证 TypeScript 类型安全与生产构建（`npm run lint` / `npm run build`）。
