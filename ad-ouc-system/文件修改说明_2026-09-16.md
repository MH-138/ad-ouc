## 二、逐文件改动说明

### 修改项 1：BUG-INTAKE-05 — 建档弹窗选项对齐

#### ① `src/types/assessment.ts` — 类型定义扩展

`SubjectRecord.demographics.maritalStatus` 联合类型新增 `0`：

```ts
// 改前
maritalStatus: 1 | 2 | 3 | 4 | 5; // 1.已婚 2.未婚 3.离异 4.丧偶 5.再婚
// 改后
maritalStatus: 0 | 1 | 2 | 3 | 4 | 5; // 0.未知/不愿透露 1.已婚 2.未婚 3.离异 4.丧偶 5.再婚
```

数字枚举扩展，与现有 `SubjectRecord` 模型一致，低风险；原有 `1~5` 取值全部兼容。

#### ② `src/components/NewPatientModal.tsx` — 弹窗 UI 与提交（均为"新增"，不改既有行为）

1. **性别状态类型放宽 + 新增"未知 / 不愿透露"按钮**

   ```tsx
   const [gender, setGender] = useState<0 | 1 | 2>(1);   // 改前 <1 | 2>
   // 按钮区新增第三个按钮（三态高亮）：
   <button type="button" onClick={() => setGender(0)}
     className={`flex-1 py-1.5 rounded-lg font-bold transition cursor-pointer ${
       gender === 0 ? "bg-teal-600 text-white shadow-xs" : "text-slate-600 hover:text-slate-900"
     }`}>未知 / 不愿透露</button>
   ```

   原有「男」「女」按钮与全部 `setGender(1/2)` 调用（`1|2` 字面量对 `0|1|2` 类型安全）均不变。
2. **婚姻下拉**新增一项：`<option value={0}>未知 / 不愿透露</option>`
3. **居住下拉**新增两项：`<option value={5}>其他</option>`、`<option value={0}>未知 / 不愿透露</option>`
4. **提交时断言类型同步**：

   ```tsx
   maritalStatus: maritalStatus as 0 | 1 | 2 | 3 | 4 | 5,   // 改前 as 1 | 2 | 3 | 4 | 5
   ```

   居住提交逻辑 `livingAlone: livingStatus === 1 ? 1 : 2` 不变——新增值 `0/5` 自然归入"非独居"，类型与语义均正确。

### 修改项 2：BUG-OTHER-02 — 研究编号查重

#### ③ `server/turso.ts` — `upsertPatient` 中 `researchNo` 生成逻辑

```ts
// 改前：纯随机、无查重
const researchNo = data.researchNo || data.subjectNo ||
  `S${new Date().getFullYear().toString().slice(-2)}-${Math.floor(1000 + Math.random() * 9000)}`;

// 改后：优先沿用传入编号；否则生成 SYY-NNNN 并查库去重，最多重试 5 次
let researchNo = data.researchNo || data.subjectNo;
if (!researchNo) {
  const genResearchNo = () =>
    `S${new Date().getFullYear().toString().slice(-2)}-${Math.floor(1000 + Math.random() * 9000)}`;
  researchNo = genResearchNo();
  for (let attempt = 0; attempt < 5; attempt++) {
    const collision = await db.execute({
      sql: "SELECT 1 FROM patients WHERE research_no = ? LIMIT 1",
      args: [researchNo],
    });
    if (!collision.rows || collision.rows.length === 0) break;
    researchNo = genResearchNo();
  }
}
```

**关键**：查重**只对后端自动生成的 `Sxx-NNNN` 触发**；前端传入的 `subjectNo`（如 `01-XXXX`）或显式 `researchNo` 原样保留，不触发查重。该路径是所有建档入口（含 OCR `persistPatientRecord`）共享逻辑，因此**既有建档行为完全不变**。
