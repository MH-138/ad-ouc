# 系统文档归属与阅读次序说明

## 1. 目的

明确本代码库各文档的职责边界、当前地位与阅读次序，指导后续维护与功能验收。

## 2. 系统核心维护文档

以下文档属于系统当前维护文档，按实际业务演进持续修订：

| 文档 | 用途 | 当前地位 |
|---|---|---|
| `P3_三端业务流程定稿.md` | 三端身份、入口、页面流程、数据流转与审核闭环 | **当前唯一业务实施基准** |
| `接口与数据表定义文档.md` | 4大核心数据表（LibSQL/SQLite）字段定义与 16 个 HTTP 接口规范 | **系统技术与数据定义基准** |
| `认知障碍早期诊断临床数据采集系统_需求文档_已更新.md` | 临床项目原始需求与业务背景 | 需求输入来源 |
| `API_AND_DATA_SPEC.md` | 接口与临床数据技术契约 | 专项技术契约 |
| `P2_接口设计与OCR结构化解析交付文档.md` | 医疗文档 OCR 解析与结构化 JSON 方案 | 专项技术说明 |
| `CHANGELOG_AND_IMPROVEMENTS.md` | 系统代码改动与业务优化留痕明细 | 变更日志 |
| `01_当前实现差距与后续修改顺序.md` | 业务差距清单与阶段验收状态核查 | 验收进度清单 |
| `P1_功能迁移与云端数据库接入说明.md` | P1 阶段迁移技术记录 | 历史阶段记录 |
| `P2_工作交付与版本迭代说明.md` | P2 阶段迭代记录 | 历史阶段记录 |
| `README.md` | 工程概述、运行指南与快速上手 | 运行说明文档 |

## 3. 根目录历史原型与参考资料

仓库根目录下保留的历史原型资料统一按只读处理：

- `README.md`（根目录）：V1.0 原始项目说明
- `README2.md`（根目录）：V2.0 患者基础信息采集说明
- `README3.md`（根目录）：V3.0 系统重构交付说明
- `ad-ouc-prototype/`：历史版本 HTML/JS 交互原型目录

以上历史文件完整保留，作为早期原型交互参考，新现代系统的所有源代码均物理隔离于 `ad-ouc-system/`。

---

## 4. 文档优先级

发生规则冲突时按以下顺序执行：

1. 临床专家与用户最新确认的业务决定。
2. `P3_三端业务流程定稿.md`。
3. `接口与数据表定义文档.md`。
4. `认知障碍早期诊断临床数据采集系统_需求文档_已更新.md`。
5. `API_AND_DATA_SPEC.md` 和 P2 专项技术文档。
6. P1、P2、CHANGELOG 等历史阶段记录。
7. 历史原型文档，仅作为原型参考，不决定新系统的业务流程。

---

## 5. 代码与工程物理隔离

| 区域 | 归属 | 维护规则 |
|---|---|---|
| `ad-ouc-prototype/` | 历史版本交互原型 | 严格只读，禁止改动 |
| `ad-ouc-system/src/` | 现代 React 19 + TypeScript 前端 | 持续迭代维护 |
| `ad-ouc-system/server/`、`server.ts` | Node.js Express 后端与 Turso 数据库 | 持续迭代维护 |
| `ad-ouc-system/` 文档 | 系统工程文档 | 持续迭代维护 |
