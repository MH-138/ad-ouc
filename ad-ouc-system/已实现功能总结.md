# 目前已实现的功能

> 对象：`ad-ouc-system/`（V3.2 全栈交付版）
> 说明：本文件为功能实现情况总结，供汇报/进度文档引用。

## 一、总体完成度

1. **后端业务接口框架、主要业务功能和接口文档已完成，可独立本地运行。**
2. **Web 前端主体已完成约 90%**，包括：
   - React 19 + TypeScript + Vite 6 + Tailwind 4 项目框架
   - 三端独立通道入口（受试者 / 家属 / 医生），彻底解耦、无跨端角色切换
   - 受试者自评端
   - 家属知情者观察端
   - 医生端 17 个功能页（含初筛、量表、分级、报告、工具箱、规范手册）
   - 全局弹窗组件（AI 研判、医生签字审核、A4 打印、病历上传/OCR、新建档案、受试者选择）
   - 评定计时器与手绘白板工具箱
   - 栅格自适应布局（以桌面端为主）
3. **前端已通过 TypeScript 类型检查**（`tsc --noEmit` 0 错误），可完成生产构建（前端静态资源 + 后端单文件服务）。
4. **前端已按后端接口格式完成真实接口适配，可直接读写云数据库**；同时保留本地缓存兜底，断网/无 Token 亦可演示。
5. **全程无跨端切换与预设假分**：空白档案严格显示 `-- / 待评定`，不把未作答当作 0 分或正常。

## 二、后端接口与数据层

1. **服务框架已完成**
   - Express + tsx 单进程运行，同时托管前端页面与 REST API
   - 开发态热更、生产态打包为单文件服务

2. **已实现 20 余个 REST 接口**，覆盖：
   - 健康检查与数据库连接状态
   - 受试者档案 增 / 查 / 改 / 删（含模糊搜索）
   - 量表评估记录提交
   - 三端草稿多流程读写（按 `role + flowId` 隔离，解决同角色多业务流互相覆盖）
   - 标准队列播种与一键重置
   - AI 综合量表分析 / AI 临床研判
   - AI 咨询单提交、待审核列表、医生审核签字
   - 病历 OCR 解析、样例病历获取
   - AI 手绘测验评分

3. **数据库已完成 4 张业务表**（LibSQL / Turso 云库 + 本地文件库双模式）
   - `patients` 受试者主档案
   - `assessments` 量表评估记录
   - `drafts` 草稿（联合主键 `patient_id + role + flow_id`，含旧表结构自动迁移）
   - `ai_consultations` AI 咨询单与医生审核状态
   - 另有 `documents`、`notifications` 两张预留表，暂未接入业务

4. **离线与降级能力已完成**
   - 缺云库 Token 时自动切换本地文件库运行
   - 缺 AI Key 时 AI 研判 / OCR 解析走规则引擎兜底，核心量表与三端流程不受影响

## 三、受试者（患者）自评端

1. **未建档先补基本信息**，已建档直接进入自评。
2. **SCD-Q9 主观认知下降自评**：15 题（9 项核心 + 6 项生活情景题），支持逐题作答与整卷跳过。
3. **附加自评量表**：GDS-15 情绪心理、PSQI 睡眠与生活节律。
4. **适老交互**：大字号、口语化题干与提示、语音朗读（TTS）。
5. **我的健康档案**：只展示本人可理解的信息，剥离内部量表结论与医生诊断。
6. **草稿与同步**：按角色保存完整草稿；医生签署医嘱后本人可实时查看。

## 四、家属 / 知情者观察端

1. **绑定唯一受试者**，不可跨受试者切换，保证数据归属正确。
2. **FAQ 日常生活能力问卷**：10 项，未答满时总分保持为空（不记 0 分）。
3. **CDR 家属核实**：对记忆、定向、判断、社会活动等维度作知情者补充评定。
4. **草稿隔离**：以 `flowId = faq_cdr` 独立保存，不与受试者自评互相覆盖。
5. **医嘱同步**：医生未出具结论前严格显示「等待主治医生综合评估」。

## 五、医生端（17 个功能页，分 5 大类）

1. **档案与自评**
   - 受试者档案与随访队列中心：队列检索、纵向随访时间轴、教学案例载入、档案删除
   - 适老沉浸式语音对话自评：决策树驱动的主题式问答，可切换专业量表工作台

2. **基础与主诉**
   - A–G 受试者基本信息与完整病史：人口学、主诉现病史、既往史、体格检查、化验
   - D / E / H16 SCD-Q9 主观认知下降评定（≥5 分阳性判定）

3. **神经心理量表库**（8 页，约 21 个量表）
   - H1 / H2 爱丁堡利手量表 + MMSE 简易精神状态（含双五边形画板）
   - H15 MoCA-B 蒙特利尔认知评估基础版（含画钟）
   - H3 / LM 华山听觉词语学习 AVLT-H（N1–N7）+ 逻辑记忆篇章
   - H4 / H5 动物流畅性 VFT（分段 1 分钟）+ BNT-30 波士顿命名
   - H6 / H8 形状连线测验 STT-A/B + 记忆执行筛查 MES
   - ADAS-Cog 阿尔茨海默病评定量表认知部分（12 项）

4. **临床分级与行为**
   - Global CDR 临床痴呆评定与华盛顿大学决策树（6 大维度）
   - 情绪与精神行为：GDS-15、NPI、HAMD-17、HAMA
   - 功能活动与睡眠：FAQ、PSQI、RBDSQ、ESS
   - ATN 生物标志物与临床诊断分型（Aβ / Tau / 神经退行 + 9 类综合分型 + 干预方案）

5. **报告与工具**
   - 综合认知诊断决策报告：常模偏离度红黄绿灯表、ADAS-Cog 损伤程度、诊断分类与医嘱编辑、医生审核状态切换、A4 打印
   - 神经心理测验工具箱：VFT 60 秒倒计时、STT 毫秒秒表、CDT 画钟与仿画白板
   - 宣武医院临床评定规范与常模速查手册（5 个分页：入排标准 / 施测流程 / 常模切界分 / CDR 判定 / 常见问答，含全文检索）

## 六、核心业务能力

1. **自动计分与解释引擎已完成**：20 余个计分函数覆盖全部量表，自动输出总分、维度分、常模切界与异常标记。
2. **AI 临床智能推理已完成**：
   - 结合受试者实际指标动态生成研判意见，附唯一流水号与生成时间
   - 推理过程平滑分段动画（0% → 32% → 68% → 92% → 100%）与阶段日志
   - 一键推送至主治医师待审核队列
3. **AI 手绘评阅已完成**：双五边形、画钟（CDT）、立方体三类绘图自动评分与专业评语。
4. **病历智能结构化已完成**：支持上传图片 / PDF 或直接粘贴文本，提取人口学、病史、影像与生物标志物信息并回填档案。
5. **医生审核签字闭环已完成**：AI 建议 → 待审核队列 → 医生签字/批注/确认分型 → 写回受试者档案，三端同步可见。
6. **数据导出已完成**：
   - 单人 Excel（3 个工作表：基本资料与病史 / 全套量表评定与常模 / 临床诊断与随访建议）
   - 全队列科研数据集批量导出
   - 全局「匿名化导出」开关，一键脱敏姓名、身份证号、手机号
7. **报告打印已完成**：A4 标准打印单，含打印专用样式。
8. **档案智能辅助已完成**：18 位身份证格式校验并按第 7–14 位反算出生日期与实足年龄、按第 17 位奇偶自动判定性别；支持随机一键生成测试受试者。
9. **分层标准队列已完成**：内置 4 位标准受试者（已签署随访医嘱 / 自评完成待审核 / 纯空白 × 2），用于演示与回归对比。

## 七、尚未完成 / 待补充

1. **未实现登录与账号权限体系**：三端目前为免登录直达，缺少登录页、权限菜单、账号管理与密码修改、操作日志。
2. **真实 PaddleOCR 异步任务尚未接入**：当前 OCR 解析返回内置标准样例并标记 `isDemo`，需医生确认后才写入档案。
3. **两条预留数据表未启用**：`documents`（文档中心）、`notifications`（消息通知）。
4. **数据看板未建设**：目前只有队列计数，暂无图表型统计看板。
5. **未做移动端专门适配**：现有布局以桌面栅格为主。
6. **尚未支持多中心 / 多机构协同**与随访复诊计划管理。
